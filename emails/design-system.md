# SkyShotConner Email Design System

## Brand direction

Premium aviation editorial. Quiet, cinematic, precise and spacious. Emails should feel like an extension of the SkyShotConner website and canvas packaging — never like a generic ecommerce template.

## Core palette

| Token | Value | Use |
|---|---|---|
| Ink | `#0A0A09` | Page background / primary dark surface |
| Panel | `#11110F` | Email cards and elevated surfaces |
| Line | `#30302B` | Borders and dividers |
| Paper | `#F5F4F0` | Primary text / light surfaces |
| Muted | `#C5C4BE` | Secondary text |
| Faint | `#8E8D87` | Metadata / supporting copy |
| Accent | `#1B302A` | Subtle aviation green accent |

## Typography

- Primary: Arial, Helvetica, sans-serif for reliable email-client rendering.
- Headings: light/regular weight, large, restrained, uppercase only where useful.
- Eyebrows: 9–11px, uppercase, `letter-spacing: 0.18em`.
- Body: 14–16px, line-height 1.65.
- Metadata: 10–12px, uppercase, letter-spacing 0.08–0.12em.

## Layout

- Maximum content width: 600px.
- Outer page padding: 20–24px.
- Main card padding: 28–36px desktop; 22px mobile.
- Use generous vertical spacing rather than heavy decoration.
- Prefer one primary action per email.
- Buttons should be rectangular, compact and editorial rather than rounded SaaS-style pills.

## Header

`SKYSHOTCONNER` as the wordmark, with the descriptor:

`AVIATION CAPTURED AS ART.`

Keep the header minimal. No large navigation menu inside emails.

## Hero / message hierarchy

1. Small eyebrow.
2. Strong headline.
3. Short supporting paragraph.
4. Primary CTA.
5. Optional secondary information block.

## CTA

Primary button:
- Background: `#F5F4F0`
- Text: `#0A0A09`
- 11–12px uppercase text
- Slight letter spacing
- 44px minimum height

Secondary action:
- Transparent background
- 1px `#30302B` border
- Paper text

## Cards and data

Use dark panels with thin borders for order details, canvas specifications and account information. Avoid excessive shadows.

## Footer

Footer copy:

`SKYSHOTCONNER`
`Aviation captured as art.`

Then compact links for Privacy, Terms and Contact. Finish with:

`The Art of Flight.`

## Email-specific rules

- All important information must remain readable without images.
- Never rely on color alone to communicate status.
- Keep images optional and use descriptive alt text.
- Use table-based layout for the actual HTML email templates.
- Inline critical CSS for broad client compatibility.
- Avoid external web fonts; use the system font stack.
- Keep authentication emails especially simple and focused.

## Planned templates

1. Confirm your email
2. Reset your password
3. Magic link / sign in
4. Welcome to SkyShotConner
5. Order received
6. Payment confirmed
7. Order dispatched
8. Canvas / Certificate of Authenticity information

## Voice

Confident, warm and concise. Never overuse exclamation marks. The customer should feel that they bought a considered piece of aviation art, not an anonymous commodity.
